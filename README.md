# هم‌خدمت | همراه دوران خدمت

## وضعیت نسخه
نسخه ۵ یک نسخه محلی (Local-first) و قابل نصب به‌صورت PWA است. اطلاعات شخصی این نسخه در حافظه مرورگر همان دستگاه نگهداری می‌شود و هنوز بین دستگاه‌ها همگام‌سازی نمی‌شود.

## پیشرفت انجام‌شده
- [x] هویت اولیه محصول، رابط فارسی و چیدمان راست‌به‌چپ
- [x] ساختار PWA، فایل manifest، آیکون‌ها و Service Worker
- [x] داشبورد و ناوبری واکنش‌گرا
- [x] روزشمار خدمت با ذخیره محلی و محاسبه تاریخ پایان تخمینی
- [x] انتخاب تاریخ شروع با تقویم شمسی اختصاصی
- [x] تقویم شمسی شخصی برای ثبت خاطره و یادداشت
- [x] رفع خطای ترتیب بارگذاری موتور تبدیل تاریخ که مانع اجرای انتخاب‌گرها می‌شد
- [x] انتخاب پوسته روشن، تیره و هماهنگ با دستگاه
- [x] تنظیم زبان رابط: فارسی، انگلیسی و عربی (ترجمه فعلی برای بخش‌های اصلی و ناوبری؛ تکمیل ترجمه تمام متن‌ها در مرحله بازبینی)
- [x] نمایش زنده تاریخ و ساعت در نوار بالا و صفحه تنظیمات
- [x] صفحه تنظیمات شامل پوسته، زبان، مجوز اعلان و یادآوری
- [x] نسخه‌بندی جدید کش PWA
- [x] صفحات نمونه انجمن، بازارچه، دوستان، پیام‌ها، اخبار، سرگرمی و پروفایل

## محدودیت‌های شناخته‌شده
- اعلان سیستم نیازمند پشتیبانی مرورگر و اجازه کاربر است. یادآوری زمان‌بندی‌شده در زمان بسته بودن برنامه، بدون Push Service و سرور تضمین نمی‌شود.
- انجمن، بازارچه، دوستان و پیام‌رسان فعلاً محلی/نمونه هستند و به کاربران دیگر متصل نیستند.
- ثبت‌نام، ورود، بازیابی رمز، بارگذاری رسانه، جست‌وجوی سراسری و همگام‌سازی ابری هنوز پیاده‌سازی نشده‌اند.
- تاریخ و ساعت از تنظیمات زمانی دستگاه خوانده می‌شود؛ انتخاب منطقه زمانی مستقل هنوز وجود ندارد.
- ترجمه انگلیسی و عربی در این نسخه جزئی است و ترجمه همه صفحات در بازبینی بعدی تکمیل می‌شود.

## فاز بعدی: فاز ۶ بازبینی رابط و تکمیل تجربه کاربری
- [ ] تکمیل ترجمه تمام صفحات و پیام‌ها به فارسی، انگلیسی و عربی
- [ ] آزمون تقویم شمسی در بازه‌های کبیسه و انتهای سال و آزمون انتخاب تاریخ روی Android
- [ ] یکپارچه‌سازی انتخاب تاریخ شمسی در همه فرم‌های تاریخ
- [ ] بازبینی دسترس‌پذیری، اندازه لمس، کنتراست و آیکون‌ها
- [ ] بررسی رفتار پوسته تیره در تمام صفحات و اجزای تعاملی
- [ ] آزمون مجوز اعلان در مرورگرهای موبایل و مستندسازی محدودیت‌های هر مرورگر
- [ ] تست آفلاین، به‌روزرسانی Service Worker و پاک‌سازی کش قدیمی

## فازهای بعد از تکمیل طراحی
1. معماری فنی و انتخاب سرویس‌های میزبانی
2. طراحی پایگاه داده و مدل اطلاعات
3. احراز هویت امن و مدیریت نشست
4. همگام‌سازی روزشمار، تقویم و پروفایل
5. انجمن آنلاین، گزارش محتوا و مدیریت
6. دوستان و پیام‌رسان برخط
7. بازارچه و مدیریت آگهی‌ها
8. اعلان‌های Push و مدیریت ترجیحات
9. پنل مدیریت، نقش‌ها و سطح دسترسی
10. امنیت، حریم خصوصی، پشتیبان‌گیری و پایش
11. آزمون نهایی، بهینه‌سازی و انتشار

## اصول حریم خصوصی
- اطلاعات حساس مانند موقعیت دقیق، جزئیات یگان یا داده‌های شناسایی‌کننده نباید در محتوای عمومی منتشر شوند.
- نسخه محلی هیچ رمز عبور واقعی دریافت یا ذخیره نمی‌کند.
- تا پیش از راه‌اندازی زیرساخت امن، قابلیت‌های اجتماعی صرفاً نمایشی یا محلی هستند.
