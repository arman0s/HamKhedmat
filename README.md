# هم‌خدمت — نسخه اولیه PWA

یک نمونه اولیه راست‌چین و فارسی برای پلتفرم روزشمار و جامعه سربازان.

## امکانات فعال در این نسخه
- رابط واکنش‌گرا برای موبایل و دسکتاپ
- ساختار PWA، manifest و service worker
- کش فایل‌های اصلی برای بازدید آفلاین پس از بارگذاری اولیه
- روزشمار بر اساس تاریخ شروع و مدت ماهانه واردشده
- ذخیره محلی روزشمار، یادداشت‌ها و خاطرات با localStorage
- صفحات نمایشی خانه، روزشمار، انجمن، بازارچه، چت، تقویم، سرگرمی، اخبار و پروفایل

## مواردی که هنوز بک‌اند ندارند
چت چندکاربره، ثبت‌نام و ورود، همگام‌سازی، انتشار عمومی پست و آگهی، اعلان‌های سروری، پنل مدیریت و کنترل محتوا. پیام‌های داخل رابط درباره نمونه بودن این قابلیت‌ها عمدی هستند؛ این موارد نباید بدون سرور و احراز هویت واقعی، آنلاین یا امن معرفی شوند.

## اجرای محلی
به دلیل محدودیت PWA، پروژه را از طریق localhost یا HTTPS اجرا کنید، نه با باز کردن مستقیم فایل HTML.

با Python:
```bash
python -m http.server 8000
```
سپس در مرورگر باز کنید:
`http://localhost:8000`

یا با هر وب‌سرور استاتیک دیگری پوشه پروژه را میزبانی کنید.

## نصب
- Android/Chromium: از منوی مرورگر گزینه Install app / Add to Home Screen
- iOS: در Safari از Share و سپس Add to Home Screen
- دسکتاپ: آیکون نصب در نوار آدرس مرورگرهای پشتیبانی‌شده

## نکته مهم
تاریخ پایان محاسبه‌شده تخمینی است. مدت خدمت، کسری‌ها، وقفه‌ها و مقررات می‌توانند با شرایط شخصی و تغییر مقررات متفاوت باشند. برای تصمیم‌گیری رسمی، مرجع رسمی مربوط را بررسی کنید.
