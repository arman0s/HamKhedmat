# هم‌خدمت — نسخه ۲ (نمونه موبایل‌محور)

رابط فارسی RTL و واکنش‌گرا برای روزشمار خدمت، تقویم هجری شمسی، خاطرات، انجمن، پروفایل، فهرست دوستان و نمونه پیام‌رسان.

## امکانات فعال در این نسخه
- روزشمار تخمینی با تاریخ شروع، مدت خدمت به ماه، تاریخ پایان، روزهای سپری‌شده/باقی‌مانده و درصد پیشرفت
- تقویم هجری شمسی با جابه‌جایی ماه، نشانگر امروز و روزهای دارای یادداشت
- ثبت یادداشت و خاطره روی دستگاه
- پروفایل محلی، نام مستعار و معرفی کوتاه
- پست، پسندیدن، نظر و گزارش در نمونه محلی انجمن
- فهرست دوستان و پیام‌های آزمایشی محلی
- PWA manifest، آیکون‌های PNG استاندارد و service worker با کش نسخه جدید

## محدودیت‌های مهم
این نسخه یک **نمونه سمت کاربر (frontend prototype)** است. اطلاعات با `localStorage` فقط در مرورگر همان دستگاه ذخیره می‌شوند. حساب کاربری واقعی، رمز عبور، ورود امن، بازیابی رمز، جست‌وجوی افراد، درخواست دوستی بین کاربران، چت زنده، انتشار عمومی پست و مدیریت محتوا فعال نیستند. هیچ‌یک از پیام‌ها یا پست‌های محلی به کاربران دیگر ارسال نمی‌شود.

برای فعال‌سازی این قابلیت‌ها باید یک backend امن مانند Supabase یا سرور اختصاصی پیکربندی شود، سیاست‌های دسترسی (RLS)، احراز هویت، محدودیت نرخ، گزارش تخلف و مدیریت داده‌ها تنظیم شوند. کلیدهای محرمانه نباید در فایل‌های عمومی GitHub قرار بگیرند. کلید عمومی anon نیز فقط همراه با سیاست‌های دسترسی صحیح استفاده شود.

## انتشار در GitHub Pages با گوشی
1. ZIP را استخراج کنید.
2. محتویات پوشه `hamkhedmat` را در ریشه مخزن GitHub بارگذاری و فایل‌های قبلی را جایگزین کنید.
3. پوشه `assets` را هم با هر سه فایل `icon.svg`, `icon-192.png`, `icon-512.png` بارگذاری کنید.
4. در Settings → Pages، شاخه `main` و پوشه `/(root)` را انتخاب کنید.
5. پس از انتشار، سایت را در Chrome باز کنید. اگر نسخه قدیمی کش شد، یک بار داده‌های سایت/کش را پاک کنید یا در تب ناشناس بررسی کنید.

## یادآوری روزشمار
مدت خدمت و تاریخ پایان صرفاً تخمینی‌اند و باید با اطلاعات رسمی و شرایط فردی تطبیق داده شوند. تاریخ‌های تقویم در رابط به هجری شمسی نمایش داده می‌شوند؛ ورودی تاریخ سیستم ممکن است در برخی گوشی‌ها با قالب میلادی باز شود.

## حریم خصوصی
از درج شماره ملی، شماره تماس عمومی، محل دقیق یگان، برنامه‌های جابه‌جایی، اطلاعات عملیاتی یا هر داده حساس خودداری کنید. داده‌های محلی با پاک‌کردن داده‌های مرورگر از بین می‌روند و این نسخه همگام‌سازی ابری ندارد.
