# هم‌خدمت — نسخه ۳

نسخه فارسی، راست‌چین و موبایل‌محور هم‌خدمت؛ همراه دوران خدمت. این پروژه یک PWA فرانت‌اند و local-first است.

## تغییرات نسخه ۳
- حفظ امکانات و صفحات نسخه ۲
- بهبود محاسبه و نمایش جزئیات زمان باقی‌مانده در روزشمار
- جلوگیری از بیشتر شدن روزهای سپری‌شده از کل بازه تخمینی
- اصلاح محاسبه تعداد روزهای ماه شمسی بر اساس تبدیل تاریخ
- نمایش یادداشت‌های تقویم به ترتیب تاریخ
- امکان حذف یادداشت تقویم از فهرست همان ماه
- شناسه‌دار شدن یادداشت‌های جدید برای حذف دقیق‌تر
- به‌روزرسانی Service Worker به کش نسخه ۳ و فعال‌سازی فوری نسخه جدید
- یادآوری حریم خصوصی در بخش تقویم

## امکانات فعال
- داشبورد و روزشمار تخمینی با تاریخ شروع و مدت خدمت
- تقویم هجری شمسی و جابه‌جایی ماه‌ها
- ثبت یادداشت و خاطره روی دستگاه
- پروفایل محلی، نام مستعار و معرفی کوتاه
- نمونه محلی انجمن، پسندیدن، نظر و گزارش
- فهرست محلی دوستان و پیام‌های آزمایشی
- PWA manifest، آیکون‌های PNG و Service Worker

## محدودیت‌ها
این نسخه فقط فرانت‌اند است. اطلاعات در `localStorage` مرورگر همان دستگاه ذخیره می‌شوند. حساب کاربری واقعی، همگام‌سازی، چت زنده، انتشار عمومی پست و آگهی، اعلان پوش و پنل مدیریت هنوز فعال نیستند. پیام‌ها و پست‌های محلی به شخص دیگری ارسال نمی‌شوند.

## انتشار با گوشی در GitHub
1. فایل ZIP را استخراج کن.
2. وارد پوشه `hamkhedmat-pwa` شو.
3. تمام فایل‌ها و پوشه `assets` را در ریشه مخزن GitHub بارگذاری کن و نسخه قبلی را جایگزین کن.
4. مطمئن شو این فایل‌ها در ریشه مخزن هستند: `index.html`، `styles.css`، `app.js`، `manifest.webmanifest`، `sw.js` و پوشه `assets`.
5. سایت GitHub Pages را باز کن. اگر نسخه قبلی نمایش داده شد، صفحه را یک بار با بارگذاری مجدد کامل باز کن یا داده‌های سایت را پاک کن.

## حریم خصوصی و دقت
- روزشمار صرفاً تخمینی است و جایگزین اطلاعات رسمی نیست.
- تاریخ پایان بر اساس افزودن تعداد ماه واردشده به تاریخ شروع محاسبه می‌شود.
- از ثبت شماره ملی، شماره تماس عمومی، محل دقیق یگان، برنامه جابه‌جایی یا اطلاعات حساس خودداری کن.
- داده‌ها با پاک کردن داده‌های مرورگر از بین می‌روند و پشتیبان ابری ندارند.

## مراحل بعدی پروژه
طراحی و تکمیل رابط پروفایل، انجمن، پیام‌رسان، بازارچه، اخبار/آموزش و مدیریت؛ سپس معماری backend، پایگاه داده، احراز هویت، امنیت و همگام‌سازی.


## نسخه ۴
- انتخاب تاریخ شروع خدمت با تقویم شمسی داخل برنامه؛ تاریخ‌های آینده قابل انتخاب نیستند.
- تاریخ انتخابی برای محاسبات به‌صورت داخلی در قالب میلادی استاندارد ذخیره می‌شود تا محاسبه پایان خدمت و سازگاری داده‌های قبلی حفظ شود.
- شناسه کش PWA به hamkhedmat-v4 تغییر کرده است.
